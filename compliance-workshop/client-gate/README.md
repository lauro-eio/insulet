# Client gate — Legal / HR review + demo peek

Self-contained HTML for Insulet Legal/People review and a short public-facing workshop teaser.

| File | Role |
| --- | --- |
| [`review-pack.html`](review-pack.html) | Legal/HR sign-off pack (handouts, claims, contacts) — Print / Save as PDF |
| [`sneak-peek.html`](sneak-peek.html) | **Demo excerpt** — 7-slide click-through (arrow keys) |
| [`sneak-peek.md`](sneak-peek.md) | Markdown blueprint for the sneak peek |

**Not included in sneak peek:** Facilitator scripts, poll keys, handout contact directories, full 32-slide decks.

## How to use

### Client gate (Legal/HR)
1. Open `review-pack.html` → Print / Save as PDF or share privately.
2. Capture sign-off; freeze contact edits into `../handouts/` if needed.

### Sneak peek (demo / sales)
1. Open `sneak-peek.html` locally or via Vercel (`/compliance-workshop/client-gate/sneak-peek.html`).
2. Navigate with **Next** or ← → keys.
3. Watermarked *Demo excerpt — not the full workshop*; no live contact emails.
